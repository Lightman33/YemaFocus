第一次使用：按步骤连接手机和电脑

在浏览器自行打开 github.com。以下英文名称来自本项目已核实的 GitHub 文档，实际界面可能略有不同。

  1. 先验证账号邮箱。点右上角加号 → New repository，在 Owner 选自己、填写 Repository name。数据仓库选择私有（Private），把 Add README 切到 On，再点 Create repository。
  2. 点头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。填写 Token name、在 Expiration 选择有效期；文档没有列出界面具体有哪些有效期选项。
  3. Resource owner 选自己；Repository access 选 Only select repositories，在 Selected repositories 只选这个私有数据仓库。在 Permissions 中把 Contents 设为读写（read、write；文档未写具体点哪里）。点 Generate token 后马上复制保存。
  4. 回到这里填写所有者、仓库名、令牌和设备名，点“保存设置”，再点“测试连接”。测试只验证可读，请确认令牌有写权限。
  5. 先在电脑上开启同步并发布一次，再在手机点“从电脑加入”。加入成功后即可编辑，修改先存本机，再自动上传。未加入之前不会自动连接 GitHub。

连接 GitHub

令牌像一把只开这个仓库的钥匙，请只授权你的私有数据仓库。令牌只保存在这台手机的当前浏览器中，连接时直接发给 GitHub。

不要填写 GitHub 登录密码；设备名和令牌均不会被放进网页链接。
